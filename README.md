# Café Origen — Analítica de ventas

## Descripción

Proyecto de análisis de ventas de Café Origen. Se utilizan arreglos de objetos en JavaScript para almacenar y explorar registros de ventas.

## Objetivo

Construir una base de datos inicial que permita realizar análisis mediante recorridos, filtros, transformaciones y acumulaciones.

## Estructura del proyecto

cafe-origen-analitica/
├── src/
│   ├── datos.js
│   ├── analitica.js
│   └── explorar.js
├── bitacora.md
└── README.md


## Tecnologías

- JavaScript
- Node.js
- Git y GitHub

## Ejecución

Desde la terminal, ejecutar:

bash
node src/explorar.js
